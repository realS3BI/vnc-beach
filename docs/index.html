VNC Beach GitHub ↗
Kostenlos · Open Source · macOS & Windows

Bildschirm teilen, ganz entspannt.

VNC Beach ist ein VNC-Server und -Viewer für macOS und Windows. Er spricht das ganz normale VNC-Protokoll, kostet nichts und wird nichts kosten.

Herunterladen So geht's

Builds für Windows und macOS liegen bei den GitHub-Releases. Wer mag, baut selbst mit cargo.

Was drin ist

Ein Viewer und ein Server für beide Systeme. Auf dem Mac geht auch die eingebaute Bildschirmfreigabe, nur die Zwischenablage gibt es dann nicht.

Viewer

macOS und Windows
  • Favoriten mit Name, Adresse und Passwort. Doppelklick verbindet.
  • Einstellungen pro Verbindung: Farbtiefe bis 256 Farben für langsame Leitungen, Nur ansehen, Originalgröße oder ans Fenster angepasst, Vollbild beim Verbinden. Alles mit Standardwerten, die jeder Favorit einzeln überschreiben kann.
  • ZRLE-Kodierung und Auflösungswechsel mitten in der Sitzung.
  • Zwischenablage in beide Richtungen, ganz ohne Zutun: was du lokal kopierst, kannst du drüben einfügen und umgekehrt.
  • Strg wird Cmd und Cmd wird Strg, sobald auf der anderen Seite ein Mac bzw. ein Windows-PC steht. Strg+Alt+Entf gibt es per Knopf.
  • Das Fenster passt sich dem entfernten Bildschirm an.
  • Aktualisiert sich selbst: Eine neue Version meldet sich beim Start und installiert sich per Klick.

Server

Windows und macOS, im selben Programm
  • Läuft im Hintergrund mit einem Symbol im Infobereich bzw. in der Menüleiste. Ein Klick darauf öffnet den Viewer.
  • Startet beim Anmelden, wenn man das möchte.
  • Status im Viewer: „Dieser Computer“ zeigt, ob der Server online ist, auf welchem Port und wer gerade zuschaut.
  • Einstellungen: Passwort, Port, Bildschirm, Bilder pro Sekunde, Nur ansehen.
  • Gibt es auch als Kommandozeilenprogramm, für Mac und Windows.
RFB 3.8

VNC Beach spricht Standard-VNC nach RFC 6143, ohne eigene Protokollerweiterungen. Darum verträgt es sich mit TigerVNC, RealVNC, Remmina, der Bildschirmfreigabe von macOS und allem anderen, das VNC kann – in beide Richtungen.

Loslegen

Eine Datei, keine Installation. Beim ersten Start zeigt der Viewer links die Favoriten und auf Windows den Stand des eigenen Servers.

Auf Windows

  1. vnc-beach.exe aus dem Release laden und starten.
  2. Unter „Dieser Computer“ auf „Einstellungen …“ klicken: Passwort merken oder neu erzeugen, Port und Bildschirm wählen, „Hintergrunddienst beim Anmelden starten“ anhaken.
  3. Ab jetzt läuft der Server im Infobereich. Von einem anderen Rechner aus verbindet man sich mit dem PC-Namen oder seiner Adresse.

Auf dem Mac

  1. Den Viewer laden und starten, Favoriten anlegen, verbinden.
  2. Soll der Mac selbst erreichbar sein: entweder unter „Dieser Computer“ den VNC-Beach-Server einschalten (mit Zwischenablage), oder die Bildschirmfreigabe von macOS nutzen (Systemeinstellungen → Allgemein → Teilen).
  3. Für den Kommandozeilen-Server braucht das Terminal Bildschirmaufnahme und Bedienungshilfen in den Datenschutz-Einstellungen.
Nur im eigenen Netz. Klassisches VNC verschlüsselt nichts, und das VNC-Passwort ist nach heutigen Maßstäben schwach. Den Port nie direkt ins Internet freigeben, sondern über ein VPN wie Tailscale oder WireGuard verbinden.

Selbst bauen

Rust installieren, dann:

git clone https://github.com/realS3BI/vnc-beach
cd vnc-beach
cargo build --release --workspace
# Viewer: target/release/beach-viewer
# Server: target/release/beach-server --password geheim
